# Politique de confidentialité — Trouve le Foin

Dernière mise à jour : 5 octobre 2026

Trouve le Foin est un jeu qui fonctionne entièrement hors ligne.

- **Aucune donnée personnelle n'est collectée**, ni transmise, ni vendue.
- Le jeu ne demande pas d'accès à Internet, à la localisation, aux contacts, à l'appareil
  photo ou au micro.
- La progression est enregistrée **uniquement sur ton appareil** (fichier de sauvegarde
  local). Elle disparaît quand l'application est désinstallée.
- Le jeu ne contient ni publicité ni outil de suivi ou d'analyse.
- Seule permission demandée : la vibration, utilisée pour les retours tactiles.

Pour toute question, ouvre une « issue » sur le dépôt GitHub du projet.
