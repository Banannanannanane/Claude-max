# Frames of sprites.png used by the game, one line per frame.
#   name = x, y, width, height
#
# The names are the game's SpriteKey values. Anything not listed here keeps the
# built-in art, and a malformed line costs only its own frame.
#
# Repeating a name adds a frame to that sprite's animation, played in file order
# at 4 frames per second off the wall clock.
#
# Source: 0x72 "16x16 DungeonTileset II" v1.7 (CC0) — see ATTRIBUTION.txt.
# The pack's tile_list_v1.7.txt gives each sprite a padded 16-wide cell; the
# rectangles below are those cells trimmed to their drawn pixels — but trimmed
# to ONE rectangle per animation, not per frame, so the bob stays a bob instead
# of being flattened out by re-centring every frame on itself.
#
# All frames share one scale, set by the tallest of them, so these sizes are also
# the cast's proportions: the ogre looms, the skull is a trinket.
