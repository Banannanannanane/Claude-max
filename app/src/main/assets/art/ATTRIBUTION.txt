Where the art comes from
========================

dungeon.png
  Pack    : 16x16 DungeonTileset II, v1.7
  Author  : 0x72 — https://0x72.itch.io/dungeontileset-ii
  Licence : CC0 (public domain), stated on the pack's page
  File    : the pack's 512x512 atlas, unmodified. The author's own list of every
            frame is kept beside it as dungeon_tile_list.txt.
  Why this one and not a tile pack: its sprites are cut out. A character drawn on
  an opaque backing plate carries that plate onto whatever it is standing in
  front of, which is exactly what a fighter in front of a wall must not do.

ui.png
  Pack    : UI Pack RPG Expansion
  Author  : Kenney — https://kenney.nl
  Licence : CC0 1.0 (public domain) — same terms as above
  File    : Spritesheet/uipack_rpg_sheet.png, unmodified.

icons.png
  Pack    : Shikashi's Fantasy Icons Pack v2
  Author  : Shikashi — https://shikashiassets.itch.io
  Licence : the author's own terms, kept verbatim in LICENSE-shikashi.txt:
            "You can use and remix these icons for commercial games and
            projects." The author also notes that many are based on designs from
            game-icons.net, which are CC BY 3.0 — hence the credit to both.
  Credit  : Shikashi, and game-icons.net (CC BY 3.0)
  File    : "#1 - Transparent Icons.png", unmodified. 32x32 cells, 16 per row.

m5x7.ttf
  Font    : m5x7
  Author  : Daniel Linssen — https://managore.itch.io/m5x7
  Licence : TO CONFIRM. The pack was supplied without its licence file. The
            author states on that page that the font is free to use with credit
            appreciated; that line has not been verified here, and no licence
            text ships beside the file. Replace this paragraph with the author's
            own wording — or the font with a CC0 one — before treating this
            repository as safely redistributable.

dungeon.txt and ui.txt are ours: they name the handful of rectangles the game
draws, using coordinates read from each pack's own metadata.

Kenney's licence asks for nothing. The credit is here because the work deserves
it, and because a public repository should say where its pixels came from.
